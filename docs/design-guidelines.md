## タイルセクション共通仕様(What's new / portfolio / history)

3つは **同一コンポーネント** `TileGridSection` + `.media-tile` を使う。個別の上書きクラス禁止。
`.media-tile` は Activities と同じ荷札カードの視覚言語（紙カード・ハトメ・点線の紐・黄色オフセット影・わずかな傾き）で統一する。
アイコン、日付/年、タイトルはこれまで通り使う。
メンバーカード（`.member-card`）も `.media-tile` を継承する。**中身の固定幅指定は禁止**（幅はカードの列に任せ、テキストは `width:100%`。固定126px時代の名残はカード枠から文字がはみ出す）。

| 項目 | PC/タブレット | スマホ |
|---|---|---|
| 列数 | auto-fit（入るだけ・最大4列。4列固定は768px近辺で傾きぶんはみ出すため禁止） | 2列 |
| タイル幅(--tile-width) | 168px | 列幅に追従（minmax(0,1fr)。固定幅は余白・影ではみ出す） |
| 画像 | 86×86 contain | 同 |
| メタ(年/日付) | 16px・画像から12px | 同 |
| 罫線 | 非表示（カード枠が区切りを担う） | 同 |
| タイトル | 13px・最大168px・折返し(pre-line) | 同 |
| グリッドgap | 列32px / 行48px | 列16px / 行24px |
| セクション上マージン | --gap-section | 同 |
| 見出し→グリッド | 32px(--tile-section-grid-gap) | 同 |

## インタラクション

- ホバーアニメーションは**クリックできる要素のみ**(`a.media-tile:hover` のようにアンカー限定で書く)。装飾画像には付けない
- ヘッダーは `max-w-[920px]` 内で logo / nav を `justify-between`。位置調整のための translate ハック禁止(横スクロールの原因)

## 2. 配置(揃え)の原則

- **ページイントロ(H1+リード)= 中央揃え**。全ページ PageIntro を通す(会員詳細は専用レイアウトだが、タイトルの書式トークンは共有)

- **セクション見出し = 中央揃え**

CSS変数に集約し、Tailwind config は `var()` 参照にする(値の二重管理をやめる):

--color-accent: #fff000;   /* 強調(黄) */
--color-line: #c7c7c7;     /* 罫線 */

計算機ページの旧専用テーマ(グレー地・青・手書きフォント)は 2026-07-03 に廃止(design-proposals.md §5 案X)。

7. `.about-copy` 13→15px、グループgap 26→24px
8. `.members-grid` margin 54→48px、`.social-grid` 34→32px、activity-history のgap 25→32px

**Phase 4: 直書き値の解消**

## 7. ビジュアル表現手法（世界観の実装）

世界観「コーヒー片手に、遊ぶように創る」を、デザインに遊び心として落とし込むときのルール。

### 7a. 色彩：シンプルだからこそ温かい

| 用途 | 色 | ルール |
|---|---|---|
| 文字・線 | `--color-ink: #070707` | 黒は使わず、深いグレー（余白とのコントラストを柔らかく） |
| 背景 | `--color-paper: #ffffff` | 白を基調に大きな余白を取る |
| アクセント | `--color-accent: #fff000` | 黄色は**極めて限定的**。コーヒー豆・電球・強調のみ |
| 補助線・グレー | `--color-muted: #555555` | 手書きイラストの輪郭や影 |

**禁止**: 新しい色を追加しない。この4色と白黒のグラデーションのみ。

### 7b. タイポグラフィ

| 箇所 | フォント |
|---|---|
| **全ページ統一** | IBM Plex Sans JP |

**原則**: フォント統一で安定感を保つ。遊び心は、手書きフォントではなく、イラスト・配置・アニメーションで表現する。

### 7c. イラスト・装飾：温かさの源

| 要素 | 表現 | トーン |
|---|---|---|
| メインキャラクター（Home hero） | Person with cup（コーヒー飲む人） | 柔らかい線、くすっと笑える表情。「賢いが肩の力を抜いている」 |
| Activity tag（Home） | ペンのシルエット + ラベル | 線画・軽快。「創り出す」というアクション感。モノトーン |
| Member portrait（Members, detail） | 手描き似顔絵 | 輪郭線は深いグレー、背景なし。個性を引き出す |
| No-image 状態 | 薄いアクセント背景 + テキスト | 「この枠は使えるよ」という親しみやすさ |

**原則**: 装飾は**目的を持つ**。かわいさだけのための装飾は排除。

### 7d. スペーシング：「焦らない」を表現

- **行間 (`--lh-reading`)**: 2.0〜2.1
  - 詰まって見えず、読むテンポがゆっくり
  - 「コーヒー飲みながら読む」感覚
- **段落間 (`--about-copy gap`)**: 32px 以上
  - 「次の段落に進む前に一呼吸」
- **セクション間 (`--gap-section`)**: 48px〜80px（幅に応じて）
  - 大きな余白でリズムを作る
- **グリッド gap**: 56px〜72px（PC）、32px〜56px（SP）
  - タイル同士が息をしている感覚

### 7e. インタラクション・アニメーション

#### ホバー状態の表現

| 要素 | ホバー表現 | 理由 |
|---|---|---|
| テキストリンク | 色変わり または 下線出現 | 明確だが派手でない |
| Activity tag（Home） | `drop-shadow` + アニメーション | 「ここクリックできる」を示唆。少し遊び心 |
| タイル（News/portfolio/members） | ホバーなし | 非リンク状態が多いため。ハイパーリンク状態なら軽く shadow |
| Social link（Footer） | 上下動き（420ms） | ほのかに生きている感覚 |

#### アニメーション全般のルール

| ルール | 説明 |
|---|---|
| **期間** | 240〜560ms。1秒以上は使わない |
| **ease 関数** | `cubic-bezier(0.22, 1, 0.36, 1)` など、自然な加速度。linear は使わない |
| **目的** | 「ここはクリックできる」「ここは生きている」を示唆する**ため**のみ。かわいさのための動きは排除 |
| **スマホ** | ホバーがないため、`:focus-visible` で代替（キーボード・タッチ操作対応） |
| **プリロード** | `prefers-reduced-motion: reduce` に対応。ユーザーが動き軽減を望めば、アニメーション停止 |

#### 禁止

- ページ遷移時の fade-in / slide（ページの安定性を損なう）
- 自動で動くエレメント（スクロール連動以外）
- 3D変形・スケール変化（読みにくくなる）
- 遅延 delay による複雑な演出（ユーザーが予測できない動きは不安定）

**原則**: 動きは**最小限**。遊び心は、動きではなく線画・余白・配置で表現する。

### 7f. 黄色の「面」コンポーネント（2026-07-03 導入、design-proposals.md 案B）

黄色を「点」から「面」へ昇格させるための4部品。いずれも4色ルール内。

| 部品 | 実装 | 使用ルール |
|---|---|---|
| マーカーハイライト | `.section-marker`（linear-gradient を文字の下半分に敷く） | LPのセクション見出しのみ。黄色反転セクション内では使わない（黄on黄で消える） |
| オフセットソリッド影 | `.home-activity-card`：常時 `4px 4px 0`、hover `7px 7px 0` + `translate(-3px,-3px)` | ぼかし影(rgba)との併用禁止。カード型リンクのみ |
| 黄色反転セクション | `.home-contact-section`：背景 `--color-accent`、ボタンは ink 反転 | **1ページ1箇所まで**。LPでは Contact us に固定 |
| NEWバッジ | `.news-badge`：黄丸+ink枠、8度傾き。NewsTile が掲載60日以内のみ自動表示 | 手動で付けない（日付判定に任せる。古い記事にNEWと嘘をつかない） |

### 7g. 荷札モチーフ（2026-07-03 導入、design-proposals.md 案C第一弾）

ヒーローの Activity tag（荷札）をLPの下層セクションへ連れていくための視覚言語。
新規イラスト素材なしで、CSSのみで構成する。

**ヒーローの荷札タグ自体もコード製**（2026-07-03、`ActivityTag.jsx` 内のSVG。tag-*.png は廃止）:

- 形状: 上下平行の水平線+上下対称の先端、同心二重丸のハトメ、紐は手前1本・奥1本（描画順: 奥の紐 → 本体 → ハトメ → 手前の紐）
- ラベルは SVG `<text>`。viewBox 基準なので幅を変えるだけで文字ごと比率が追従する（レスポンシブ配置自由）
- 影は Activities カードと同じ黄色オフセット（通常 `4px 4px 0`、hover `7px 7px 0`）で家族に見せる
- 新しいタグは `homeActivities.js` に label と位置クラスを足すだけ

| 部品 | 実装 | 意味 |
|---|---|---|
| ハトメ | `.home-activity-card::before` / `.media-tile::before`（左上の白丸+ink枠） | 「これは荷札」の記号 |
| 紐 | `::after` の 2px 点線（ヒーローの `.connector-line` と同じ線種） | ヒーローとの血縁を示す |
| 傾き | nth-child 交互に ±1deg、hover/focus で 0deg に起き上がる | 「今にも動く」静的な遊び心 |
| 紐の揺れ | hover 時のみ 560ms ひと揺れ（`string-sway`、tag-twitch と同系） | 控え目な生命感 |

**ルール**: 荷札カードは押せる/押せないに関わらず、同一セクション内の世界観を統一するために使ってよい。
ただし hover/focus の起き上がり・紐の揺れはリンクカードのみ（クリック可能性の記号として使う）。点線の紐の線種を変えない。

### 7h. チェックリスト：「遊び心がない」と感じたら

- [ ] 余白が圧迫的（逃げ場がない）→ `--gap-section` / `--lh-reading` を見直し
- [ ] 文字が詰まっているように見える → 段落間・行間を確認
- [ ] イラストの表情が硬い → 眉の角度、目の大きさを確認
- [ ] 全体が「説教臭い」感じ → ページのトーン（リード文など）を見直し
- [ ] 色が足りないように感じる → 黄色の使い方を確認。追加ではなく、既存色をより活かす
- [ ] 「何か遊び心を足そう」と思った → その前に、不要な要素を削れていないか確認。足し算ではなく引き算
