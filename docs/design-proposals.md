# 「白すぎてさみしい」を解決するデザイン案

**作成**: 2026-07-02 / 関連: [ブランド世界観](./brand-worldview.md), [デザインガイドライン](./design-guidelines.md)

参考サイト:
- [道の駅ウェルネスあらお](https://wellness-arao.com/)
- [MOS SOUND SELECTION](https://www.mos.jp/oc/mossoundselection/)

---

## 1. 参考サイトの「楽しさ」の正体

2サイトを分析すると、楽しさは次の5つの仕掛けから来ている。

| 仕掛け | ウェルネスあらお | MOS SOUND SELECTION |
|---|---|---|
| **地の色が白でない** | 白+ブルー+黄色の面切替 | 全面クリーム(肌色がかった紙色) |
| **有機的な形** | 波形のセクション区切り、ブロブに切り抜いた写真 | 大きな色ブロブが見出しの背景に敷かれる |
| **イラストが「働いている」** | キャラが自転車に乗る・収穫する等、動作している | 人物がハンバーガーを食べ、楽器が飛ぶ |
| **色面の反転セクション** | 青ベタ・黄ベタのセクションが白と交互 | 黄・緑・茶のテーマカードが並ぶ |
| **見出しの遊び** | 斜めのティッカー文字、丸いバッジ | 袋文字+ずらし影のディスプレイ文字 |

共通するのは「**白い余白を減らす」のではなく「余白に色と温度を与えている**」こと。
余白の量はどちらも多い。さみしく見えないのは、余白自体が生成りや黄色で「温かい」から。

## 2. Techreateへの翻訳 — 世界観ルールとの整合

brand-worldview.md の制約: 色の追加禁止(黒・白・グレー・黄のみ)、装飾は目的を持つ、遊び心は細部に。

→ 参考サイトの多色展開をそのまま持ち込むのではなく、
「**紙の色の再定義**」と「**黄色の使用量の増加**」で同じ効果を出す。

## 3. 三つの方向性

### 案A: 生成りの紙(推奨・基盤)

> 白い紙を、コーヒーのある机の上の「生成りの紙」に持ち替える。

- `--color-paper` を `#ffffff` → 生成り(例 `#FBF7EE`)へ。全ページ一括で温度が上がる
- カードやフォームなど「置かれた紙」は白のままにして、紙の重なりで奥行きを出す
- セクション区切りを直線から**湯気の波形**(SVG 1本)へ
- About/Contact の見出し背景に**黄色のブロブ**を1〜2箇所だけ敷く
- ※「色の追加」ではなく「紙の色の再定義」としてルール改訂する(要ガイドライン更新)

工数: 小(CSS変数1つ+波形SVG+ブロブ)。効果: 全ページに波及。

### 案B: 黄色の反転セクション(アクセント強化) — ✅ 2026-07-03 実装済み

> 4色ルール完全遵守のまま、黄色を「点」から「面」に昇格させる。

- LPの1セクション(Contact us推奨)を**黄色ベタ背景に反転**。ページにリズムが生まれる
- 見出しに**蛍光マーカー風の黄色ハイライト**(linear-gradientの下敷き)
- Activityカードのホバー影を黄色の**オフセットソリッド影**(`box-shadow: 6px 6px 0`)に
- What's new のタイルに黄色の丸バッジ(NEW表示)

工数: 小〜中。注意: 反転セクションは1ページ1箇所まで。多用すると押し付けがましくなる。

### 案C: イラストを「働かせる」(密度アップ) — 🚧 第一弾実装済み(2026-07-03)

> 第一弾: ヒーローの荷札タグをActivitiesカードに継承(ハトメ+点線の紐+傾き、CSSのみ)。
> 第二弾: ヒーローの荷札タグ自体をSVG化(tag-*.png廃止、ラベルは本物のテキスト、影は黄色で統一)。
> 第三弾: What's new / portfolio / history の `.media-tile` を荷札カード化（アイコン・日付/年・タイトルは維持、罫線はカード枠へ統合）。
> 残り: 仲間カット、送信後/404の一枚絵など、イラスト素材が必要なもの。

> 色ではなく、線画の密度と動作で楽しさを出す。ヒーローの世界観を下層まで連れていく。

- 各セクション見出しの脇に**小さな線画**(コーヒーカップ、豆、電球、ペン)を添える
- ヒーローの人物の**仲間カット**を増やす: About横で乾杯する二人、Contact横で手を振る人物
- 手描き風の**点線矢印・囲み**でCTAへ視線誘導
- フォーム送信後・404などに「くすっと笑える」一枚絵(例: コーヒーをこぼす人物)
- スクロールで湯気がゆらぐ等、**1箇所だけ**のアンビエント動作

工数: 中〜大(イラスト制作が主)。効果: 最もブランド独自性が高い。

## 4. 推奨の組み合わせ

**A(生成りの紙)を基盤に、B(黄の面)を1箇所、C(イラスト)を段階的に追加。**

即効の5手(効果順):

1. `--color-paper` を生成りへ、カードは白のまま残す
2. Contact us セクションを黄色反転に
3. 見出しにマーカーハイライト
4. セクション区切りに湯気の波形
5. セクション見出し脇にミニ線画(既存イラストの部品を再利用)

## 4b. メンバー詳細: 見出しまわりの修正案(2026-07-03) — ✅ 案2を実装済み(名前を最上段に変更)

カード化(プロフィール表・似顔絵)の後、名前・肩書・一言コメントだけが地の上に直置きで浮いている問題。

- **案1 名札カード**: 名前・SNS・肩書・一言も1枚のカードに → 浮きは消えるがカード3枚で呼吸が減る
- **案2 PageIntro式(推奨)**: 肩書=アイブロウ、名前=タイトル、一言=リードとして他ページ共通の
  「ページタイトル層」に格上げ。「タイトル層」と「カード(資料)層」の2層に整理される
- **案3 ネームタグ**: 名前をヒーローと同じSVG荷札に入れる → 遊び最大だが6人分でくどい・長い名前が窮屈
- 折衷: 案2の構成でアイブロウの肩書だけ荷札チップにする「2+3」も可

## 5. ざっくり水硬度計算機の統一デザイン案(2026-07-03) — ✅ 案Xを実装済み

> 実装メモ: ボトル・ピッチャーはPNGを廃止しSVG化(`WaterHardnessPage.jsx`内)。
> 水はグレー階調、黄色はボトルキャップ・結果ピル・計算ボタンの3点のみ。
> 見出しはPageIntro、入力欄はフォームと同じink枠+黄フォーカス。旧`--wh-*`テーマ変数は削除。

### 現状の不統一点

| 項目 | 計算機ページ | サイト共通の語彙 |
|---|---|---|
| 地の色 | グレー `#e8e6e6` | 白い紙 |
| 色 | 青(水・入力枠・ピル) | 黒・白・グレー・黄の4色 |
| 入力欄 | イタリック+青枠+青影 | ink枠+黄フォーカス(お問い合わせフォームで確立) |
| ボタン | グレー `#737373` | `cta-button`(黄地×ink / ink地×白) |
| 見出し | プレーンな中央文字 | PageIntro(アイブロウ+タイトル)+マーカー |
| 荷札言語 | なし | ヒーロー/カード/タイルまで一気通貫 |

### 案X: 家族に迎える(完全統一)

青を捨て、水をグレー階調+黄アクセントに(イラストはCSS `filter: grayscale`)。
UI部品もすべて共通部品へ。**リスク**: 水がグレーだと「美味しい水」に見えない。表現力を失う。

### 案Y: 出島方式(推奨) — 枠は家族、中身はあそび場

> ページの骨格はサイト共通、計算機本体だけを「Cafe Wa-createの道具」として荷札カードに載せる。

- 地をグレー→**白い紙**に。ヘッダー/フッターと連続させる
- 見出しを **PageIntro 形式**に(アイブロウ「Cafe Wa-create」+タイトル「ざっくり水硬度計算機」+リード)
- 計算機本体(ボトル2本+ピッチャー+ボタン)を**大きな荷札カード**(白カード+ink 2px枠+黄オフセット影+ハトメ+紐)で1枚に包む
- **カードの中だけ水の青を許す**。「青はUIの色ではなくコンテンツ(水)の色」と整理する。
  イラスト(ボトル・ピッチャー)はそのまま活きる
- UI部品を共通部品に置換:
  - 入力欄: イタリック+青枠 → お問い合わせフォームと同じ ink 1px枠+黄フォーカス影
  - 計算ボタン: `cta-button`(黄)/ クリアボタン: 白+ink枠の副ボタン
  - 結果ピル: 青 `--wh-pill` → 黄 `--color-accent`+ink文字
- 手書きフォントは見出しまたは注釈だけに限定し「計算機ページの特別感」は維持
- 計算式の注釈は湯気の波形罫線の下に置く

**効果**: 統一と遊び場の両立。青の扱いに理屈が通る。実装はCSS中心+PageIntro挿入のみ。

### 案Z: 最小介入

グレー背景と青を「専用テーマ」として公認したまま、見出しへのアイブロウ+マーカー追加、
ボタンの `cta-button` 化、境界に湯気の波形だけ。**工数最小だが統一感は部分的**。

### 推奨

**案Y**。ボトル・ピッチャーのイラストを描き直さずに済み、
「荷札カードに載った道具」としてヒーロー→カード→計算機まで世界観が一本につながる。

## 6. 実装時の禁止事項(世界観の保全)

- 多色化しない。生成り+黒+グレー+黄で止める(参考サイトの青・緑・茶は追わない)
- アニメーションを増やしすぎない。「今にも動く」感覚は静止画の傾き・配置で出す
- 手書きフォントは引き続き計算機ページのみ
